พยากรณ์ข้อมูล Time Series โดยใช้โมเดล BPNN/MLP, SGD Optimizer, L2 Regularization
ใช้โครงสร้างขนาดเล็ก (Occam's Razor): การใช้จำนวนโหนดแค่ 8 -> 4 -> 1 สมดุลพอดีกับปริมาณข้อมูล มันไม่ซับซ้อนเกินจนคิดฟุ้งซ่าน และไม่เรียบง่ายเกินจนจับแพทเทิร์นอะไรไม่ได้เลย
L2 Regularization: บรรทัดที่ใส่ kernel_regularizer ทำหน้าที่เหมือนโซ่ตรวนที่ดึง AI ไว้ไม่ให้เหวี่ยงเส้นกราฟสีแดงทะลุอวกาศเมื่อเจอกับข้อมูลหลอกในอดีต
SGD + Momentum: แม้จะล้าสมัยไปนิดเมื่อเทียบกับยุค Deep Learning แต่มันคือ Optimizer ที่ค่อยเป็นค่อยไปและ "ไว้ใจได้ที่สุด" สำหรับข้อมูลอนุกรมเวลา (Time Series) ที่มีนอยส์ (Noise) เยอะ
